# AcoAlex's C++ Projects

This repository contains a collection of small "afternoon projects" built around interesting ideas, experiments, and programming challenges.

Unless stated otherwise, all code in this repository was written by me in C++.

### Running the Projects

Each project includes a `run.md` file containing simple, copy-and-paste terminal commands for building and running the project.

### Compatibility

All projects have been tested on **Windows 11** only. Other operating systems may work, but are currently unsupported.
